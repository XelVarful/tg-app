# Band — IELTS planner

Минималистичное Telegram Mini App: задачи по Listening, Reading, Writing и Speaking, календарь, целевой балл и статистика.

## Запуск

В этой папке выполните `npm run dev` (нужен Python 3), затем откройте http://localhost:5173. Устанавливать зависимости не нужно. Интерфейс также можно открыть через index.html, но для стабильного хранения и Telegram используйте HTTP/HTTPS.

## Возможности

- Создание задач с секцией, датой и заметкой; редактирование по нажатию на название.
- Выполнение, удаление с подтверждением, фильтры по секции и статусу.
- Календарь с переключением месяцев: точки отмечают планы и фактические дни выполнения.
- Статистика по секциям, количество активных дней и серия занятий.
- Изменение целевого балла IELTS.
- Адаптивная версия для телефона и компьютера, интеграция Telegram WebApp SDK.

Данные сохраняются в localStorage этого браузера. Серверной синхронизации между устройствами нет. Приложение начинает с пустого списка; статистика показывает только ваши реальные задачи. Дата в календаре — запланированная дата задачи, день активности — фактическая дата выполнения. Возврат задачи в работу убирает её из статистики выполненных.

## Подключение к Telegram

Разместите файлы index.html, style.css и app.js на статическом HTTPS-хостинге. В @BotFather настройте Mini App или кнопку меню своего бота на полученный HTTPS URL. Локальный адрес localhost недоступен с других устройств. Токен бота во фронтенд не добавляйте.

Telegram SDK запрашивает расширение окна и показывает имя пользователя, если оно доступно. Без Telegram приложение работает в обычном браузере. Для будущего серверного хранения потребуется серверная проверка Telegram initData.

## Проверка

`npm run check` проверяет синтаксис JavaScript. Сборка не требуется.
