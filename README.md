# Band · IELTS

Минималистичный тёмный планер для мобильного Telegram. Без зависимостей и сборки.

## Запуск

`npm run dev` → http://localhost:5173 (нужны npm и Python 3).

## Интерфейс

- **Задачи**: неделя, выбор секции, список и кнопка добавления. Нажатие на кружок завершает задачу, на текст — открывает редактирование. Удаление находится внутри формы и требует подтверждения.
- **Календарь**: планы по датам и фактическое количество выполненных задач за каждый день.
- **Прогресс**: общее число выполненных задач, дни занятий, серия, четыре секции и график за неделю.

Чёрный фон, ширина до 480 px, нижняя навигация, кнопки от 44 px, поля 16 px (без автоматического увеличения на iPhone), форма с прокруткой. Учтены безопасные отступы Telegram и устройства. Telegram BackButton закрывает форму или возвращает к задачам; заголовок и нижняя панель получают цвет приложения. Используются документированные свойства Telegram SDK: https://core.telegram.org/bots/webapps.

Старые задачи сохранены: используется прежний ключ `band-ielts-v1` в localStorage. Хранение локальное, между устройствами не синхронизируется. Дата задачи — день плана; активность учитывается по фактической дате завершения. Возврат задачи в работу удаляет её из статистики выполненных. Список изначально пустой.

## Открытие из Telegram на телефоне

Разместите `index.html`, `style.css`, `timer.js` и `app.js` на HTTPS-хостинге. В @BotFather задайте этот HTTPS URL для Mini App / кнопки меню своего бота. Адрес localhost на телефоне не открывает сервер компьютера. Токен бота фронтенду не нужен.

Для локальной проверки с телефона в одной Wi-Fi сети можно использовать `http://<IP компьютера>:5173`; для запуска именно в Telegram необходим HTTPS. В реальном Telegram iOS/Android дополнительно проверьте клавиатуру, поворот экрана и сохранение после повторного открытия.

## Проверки

`npm run check` — синтаксис JavaScript. Серверная синхронизация и публикация не настроены.

## Таймер задач

У каждой незавершённой задачи есть «Начать», «Пауза» и «Продолжить». Одновременно идёт одна задача: запуск другой сохраняет время предыдущей. Завершение задачи останавливает таймер. Время остаётся у задачи и суммируется в прогрессе, включая незавершённые задачи. Удаление задачи также удаляет её время.

Активная задача видна на всех вкладках, нажатие на её название возвращает к задаче. Сохраняются накопленные миллисекунды и момент запуска. Сворачивание или закрытие приложения не ставит таймер на паузу: после открытия учитывается всё прошедшее время до ручной паузы. Отсчёт зависит от системных часов устройства. Данные остаются только в том же браузере / Telegram WebView, без синхронизации устройств.

Dynamic Island не реализован: Telegram Mini Apps не предоставляют API для произвольных Live Activities. Для этого потребуется отдельное iOS-приложение с ActivityKit и расширением виджета. Источники: https://core.telegram.org/bots/webapps и https://developer.apple.com/documentation/activitykit.

`npm test` проверяет накопление времени, паузу/возобновление, восстановление после перезапуска, переключение задачи, миграцию старых данных и связь таймера с интерфейсом. Проверки UI используют модель DOM и не заменяют проверку на физическом iPhone.
